# CyberShield

An offline cybersecurity desktop application developed using Python and Tkinter.

## Modules

- File Integrity Checker
  - SHA-256 hashing
  - File integrity verification

- Password Safety Analyzer
  - Password strength assessment
  - Password safety feedback

## Technologies Used

- Python
- Tkinter
- hashlib
- Standard Python libraries

## Project Status

Developed as an academic cybersecurity project.

- Additional security analysis modules
- Improved interface
