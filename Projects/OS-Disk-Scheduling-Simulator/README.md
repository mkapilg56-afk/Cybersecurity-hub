# OS Disk Scheduling Simulator

A graphical Operating Systems project developed using Java Swing to demonstrate disk scheduling algorithms.

## Algorithms Implemented
- FCFS (First Come First Serve)
- SCAN (Elevator Algorithm)
- C-SCAN (Circular SCAN)

## Features
- User input for disk requests
- Initial disk head position configuration
- Disk size configuration
- Algorithm selection
- Total head movement calculation
- Graphical visualization of disk head movement
- Execution sequence and individual movement analysis

## Technologies Used
- Java
- Java Swing
- Java AWT
- Object-Oriented Programming
